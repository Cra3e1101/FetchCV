# Contributing to FetchCV

Thank you for helping improve FetchCV.

1. Choose the relevant platform directory: `windows/` or `macos/`.
2. Install dependencies locally; never commit `node_modules`, virtual environments, build output, databases, API keys, resumes, or real applicant data.
3. Keep platform-specific behavior documented in that platform's README.
4. Run linting, the production build, and the relevant automated tests before opening a change.
5. Describe user-visible behavior, privacy impact, and validation results in the change summary.

Security and privacy regressions should not be filed with real credentials or personal documents attached. Use synthetic examples and redact logs before sharing them.

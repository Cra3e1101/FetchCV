## 已落地的主要改变

1. **运行时契约。** 不再依赖收不到的 `subscribe(tool_result)`；在工具执行返回前刷新能力，失败就停止。用真实 Pi Harness 验证工具刷新和动态提示词。历史记忆作为受保护的用户资料消息，不再拼进系统权限层。
2. **模型接入。** Electron 测试连接和运行时共用 Pi 适配器，规范化 Anthropic 地址；测试实际走流式工具调用和工具结果回传，区分“可对话”和“工具未验证”。模型画像接入可校验的兼容字段、输入模态和输出容量，设置页提供对应选项。输出上限由模型窗口/已知上限约束，不再统一压到 2048。
3. **失败与重试。** 工具明确区分数据库事务操作和外部副作用。只有能证明事务回滚的失败允许重新执行，外部结果未知仍需用户确认。`retry_authorized` 已接通，活动执行不允许被人工恢复接口抢占。
4. **长结果回读。** 新增按任务/对话隔离的持久化结果归档和 `read_tool_result`，截断保留真实引用、分页参数和事实 ID。不可回读的后端不会被宣称“完整结果可恢复”。数据库迁移补齐归档表及独立聊天表；归档同内容写入采用原子冲突忽略。
5. **审批与完成判定。** 简历审批绑定内容哈希；内容变化后旧批准不能继续应用。版本回滚批准后真正执行。未到可交付阶段的任务暂停，不能仅因模型循环结束就显示业务完成。
6. **面经与 OCR。** 来源就绪和简报规则统一；OCR 必须由用户核对准确文本后进入可分析状态。受门禁约束的模型原稿保留于元数据，本轮来源按时间过滤。未取消防伪造简报门禁。
7. **MCP 与 Skill。** MCP 工具名稳定映射、合法且有长度限制；限制应用密钥转发；增加完整会话超时、发现分页、策略过滤、原始错误/结构化结果保留。Skill 信任覆盖完整文件，含 frontmatter，处理 BOM、同名冲突、停用项和目录截断提示。
8. **独立聊天。** 联网批准凭据由宿主在用户确认后签名，绑定轮次、工具、参数、调用 ID 和五分钟有效期。布尔值不能代替批准；记录执行回执，重复成功调用回放已归档结果，改变同一调用 ID 的参数被拒绝。仍是独立适配路径，尚未完全并入 ToolGateway。
9. **启动诊断。** Sidecar 日志脱敏、轮转；健康检查核对实例 nonce，避免把其他端口进程误认作本次启动的后端。生产启动缺少控制令牌时业务 API 拒绝服务。

## 保留的取舍、限制和未完成项

- **双后端**：本轮新增业务只进默认 Python；V2 保留，不自动切换、不删原有能力。`BACKEND_TRANSITION_20261021.md` 是当前收敛原则，尚未完成两个后端的统一类型化端口及契约对等测试。
- **Python 单次模型调用**：JD/PDF 抽取仍有活路径，因此未直接撤掉 Python 的模型密钥；无前端调用的旧分析/策略路由已退役为 410。后续迁移需覆盖单次抽取，而非只删密钥变量。
- **上下文**：仍用偏保守的 UTF-8 字节估算，不称为精确 token 计数。分页和引用缓解长结果损失，但尚无全模型 tokenizer 或自动摘要重试。独立聊天取最近 200 条，数据库原文保留；不宣称无限记忆。
- **MCP**：本地进程不是沙箱。HTTP 自定义认证头、Windows `.cmd` 自动启动、持久会话及完整取消通知尚未支持。使用绝对可执行路径或显式 `node.exe + CLI.js`；不继承整个系统 PATH。网络 ask/deny 是本应用调用策略，不是操作系统隔离。
- **Skill**：相对资源文件读取未新增。完整文件信任哈希变更会让旧授权失效，用户需重新审阅，不静默继承旧授权。
- **权限**：独立聊天签名提高请求绑定与回放约束；它不能抵御已掌握桌面控制密钥的进程。独立聊天执行记录仍未共用 ToolGateway 的记录表。查询参数令牌仍供现有 PDF/产物显示使用，未替换为短期票据。
- **结果归档**：已有作用域、完整性、脱敏、分页、删除岗位联动清理；没有配额、保留期限和完整独立聊天删除/归档管理。归档的是脱敏后的工具结果，不承诺保存所有原始敏感字节。
- **图像/隐私**：模型画像可声明图像输入，不能因此声称所有附件已端到端接入视觉模型；附件读取和面经 OCR 各有路径。未关联候选人的聊天不猜测人名身份，仍做通用敏感信息脱敏。
- **验证缺口**：三项真实 PDF 测试因文件缺失未完成；跳过项不算通过；未调用真实付费 provider，未运行最终 NSIS 安装、桌面手动全流程或升级后数据迁移。前端构建通过不代表所有高级设置已手工操作验收。
- **Pi 升级**：仍为锁定 0.80.10；没有验证 0.99.2 的更新记录，也不把审查摘要中的“最新版本”视为重新核实过的事实。

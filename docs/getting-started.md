# 使用指南

FetchCV 围绕个人资料和目标岗位组织求职准备。建议先完成资料核对，再开始岗位定制。

## 安装与启动

当前支持从源码启动 Windows 桌面端。依赖安装命令见[项目首页](../README.md#快速开始)；安装包构建见[开发指南](development.md#构建-windows-安装包)。

首次准备 XeLaTeX 运行时需要联网，后续可复用构建缓存。自行构建的安装包包含排版运行时，使用者无需单独安装 LaTeX。

## 配置模型

在设置中添加模型连接，填写连接名称、请求地址、API Key 和模型名称，并选择对应的接口格式：

- OpenAI Chat Completions 兼容接口。
- Anthropic Messages 兼容接口。

请求地址和模型名称以服务提供方的配置为准。执行连接检查并选定模型后，即可开始对话。使用 Agent 工具时，应选择支持工具调用的模型。

API Key 在桌面主进程中通过系统能力加密保存。使用云端模型时，相关对话和材料片段会发送给所选服务，详见[数据与隐私](privacy.md)。

## 导入个人资料

在个人资料库中导入已有简历，逐项检查姓名、教育、经历、项目、日期和正文，再保存。

| 格式 | 说明 |
| --- | --- |
| PDF | 支持可提取文本的文件；扫描件需要先 OCR。 |
| Word `.docx` | 支持提取文字内容；旧 `.doc` 需要先另存为 `.docx`。 |
| LaTeX `.tex` | 静态解析源文本，不运行上传的 LaTeX 命令。 |
| JSON | 支持 FetchCV 简历快照与 JSON Resume。 |

完整旧工作区应使用“迁移旧版工作区”入口，与普通简历 JSON 导入区分。作品集、证书和代码仓库链接可以作为补充材料保存。

AI 增强识别默认关闭。启用后，需要核对实际脱敏文本并确认外发，再由模型协助整理内容；原始 PDF、头像和本地文件路径不作为该步骤的上传附件。

## 为目标岗位准备简历

1. 添加目标岗位，粘贴 JD、导入文本文件或提供公开招聘页面。
2. 在岗位对话中分析职责与要求，选择相关经历。
3. 审阅改写建议，检查岗位引文、事实依据和措辞，采用、拒绝或编辑后采用。
4. 打开简历工作台，调整内容与排版，检查 PDF 预览。
5. 完成内容核对后，选择保存位置，导出 PDF 或 Word。

基础资料与岗位简历分开保存。PDF 使用应用内模板，预览和 PDF 导出使用同一编译文件；Word 为独立的单栏可编辑版本。

## 准备面试

在岗位的面试工作区整理本地知识与公开面经。调研结果保留来源链接和引用，方便核对问题背景与岗位相关性。来源较少或无法访问时，应补充自己的材料，并结合原文判断准备重点。

## 常见问题

**本地优先是否代表完全离线？**

资料存储和部分文档处理在本机完成。云端模型、网页搜索、在线面经与首次依赖下载需要网络。

**启动时找不到 Python？**

确认已创建 `backend/.venv` 并安装后端依赖。在当前 PowerShell 中设置 `FETCHCV_PYTHON` 为该环境解释器的绝对路径，再运行 `npm run desktop:dev`。

**PDF 无法预览或导出？**

在项目根目录运行 `npm run resume:runtime`，再用 `npm run resume:runtime:verify` 检查运行时。使用内置替代字体时，换行可能与安装了宋体和 Times New Roman 的环境不同。

**招聘页面或面经无法读取？**

网站可能要求登录、验证码或限制自动访问。可以手动粘贴可使用的岗位文本，或导入自己持有的材料。

**开发模式和已安装应用的数据为何不同？**

`npm run desktop:dev` 默认使用独立开发资料目录，避免开发过程影响日常工作区。数据路径与后端调试说明见[开发指南](development.md)。

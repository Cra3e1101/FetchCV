# M7 个人事实引用增量（2026-09-27）

依据原方案 §9、§21、§22，个人事实正文只有 KnowledgeItem 一个权威。新增 PersonalFactReference 保存条目 ID、版本、内容哈希和严格原文定位；Memory 不另存一份事实正文。

用户在当前范围搜索原文后，须展开审阅并明确确认属实，才保存事实与记忆引用。Agent 只能读，不能自行确认。旧 legacy_verified_flag 保留原状，不自动获得新记忆授权。确认时间不代表事实开始发生的时间。

读取与最终回答引用审核会重查候选人/岗位、条目版本、来源状态和当前文档；来源撤回或文档失效会禁用关联条目。失效列表只保留撤回句柄，不泄露缓存原文。用户停止记忆仅撤回引用，保留事实和审计。已选中的旧 read_memory 回执在撤回后不能继续认证回答。原文精确匹配不等于语义推断已获证实。

# 2026-10-20：按本地参考文件重建共用界面

本次以 codex-ui-replica/index.html、conversation.html、replica.css 的实际 DOM 与浏览器计算样式为基准。没有使用 computer-use。没有继续采用 OpenBitFun 的设计；侧栏、输入区、审批菜单已替换为原生 React 的参考结构，main.jsx 移除了 OpenBitFun 样式入口。上游原件仍保留在仓库，未删除。

修改的是源码和候选构建，尚未替换已安装客户端、未生成 installer、未提交 GitHub。对照截图使用真实 Edge 渲染的产品代码与显式合成验收数据，不访问 APPDATA、不调用真实模型、不修改数据库。

## 本轮实际改动

- 侧栏：原生 rp-sidebar → head / scroll / section / row 层级，52px rail、288px 侧栏，首行 x62/y100、268×30。
- 输入区：原生 surface → editor + controls → start/end 结构。1296×950 下 x446/y848、744×86；编辑区34px、控制区52px、发送32×32。附件、IME、发送、停止、模型与审批接口保留。
- 会话：文字改为参考文件的14/24.5，用户气泡14/22.4；800px内容列内留24px。工具记录放在回答前，双层折叠采用 activity-header 层级。代码块采用 rp-mdx 的16px圆角和原始头/正文间距；Shell样式仅承载实际工具摘要，不伪造命令输出。
- 菜单：移除 OpenBitFun 的 Menu/MenuPopover，权限菜单按参考 rp-permmenu/rp-permrow 重建。保留真实读取、保存、拒绝保存反馈、键盘与外部点击关闭。命令菜单移除参考物没有的额外图标、页脚和 Esc 装饰。
- 设置：整页导航，搜索胶囊、标题、分组卡片、紧凑行和底部返回入口按参考重建。主题改为紧凑选择控件，取消大面积主题卡片及统计卡片，真实设置能力不变。
- IPC 工作区同步了共用布局、输入框和文字尺度，保留原桥接逻辑。它的业务设置不是 React 设置页的完整替代，仍需单独对照。

## 尚存差异与验证边界

1. 参考页内容、导航数量、固定模型列表、语音/分支/完整访问等不能假装成本项目能力；本项目保留真实业务标签、配置项与数据。取舍见上表。
2. 图标仍使用项目现有Lucide矢量，部分轮廓没有换成参考客户端的专有图标；没有宣称图标路径逐像素一致。
3. 参考静态页深色模式部分面板仍硬编码浅色。本项目用语义深色变量避免白色残留，所以这些部分有明确差异。
4. 浏览器无桌面窗口桥接，截图顶部不伪造原生窗口按钮或文件/编辑菜单；Electron原窗口控制保留。尚未在重新安装后的桌面客户端逐项验收。
5. 新增岗位、简历审阅、材料与面试知识等属于业务适配；没有参考文件可证明其全部布局1:1。主要业务接口未替换，未做真实模型、真实简历导出或全流程业务回归。
6. 动效的展开/收起、按下与开关有实际事件记录；不是所有控件每一种状态都做了独立截图。不能把93+52项通过扩大成全界面无差异。
7. 测试过程发现并修正了编辑区样式继承、设置标题/搜索坐标和工具组旧左边框等问题。早期失败/中间截图保留，不当最终结果；最终以 verified-* 为准。

# M5 DOCX 多段单元格修复（2026-10-07）

此前 DOCX 表格单元格包含多个段落时，解析器把各段文字直接拼接，例如 `项目 A：10` 与 `项目 B：20😀` 连成一个字符串。修复后在段落间保留换行；单元格之间继续使用制表符。原文块、Unicode 码点范围与单元格 origin 一致。

解析器结果版本升为 `local-structured-1.1`。导入任务协议仍为 `local-structured-1`，明确接受结果版本 1/1.1，并在新 Document 中记录实际结果版本。未知版本被拒绝。不修改旧文档、不重写旧库。同哈希已完成的旧 DOCX 导入仍走幂等路径，不会自动修复历史解析；历史重解析需独立受控流程。

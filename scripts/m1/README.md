# 环境维护工具

本目录保留用于隔离运行、文件变更监测和依赖环境维护的工具。普通开发、测试和打包入口见[开发指南](../../docs/development.md)。

这些工具依赖明确的工作根、临时目录和环境配置，不是新克隆仓库的默认启动步骤。使用前阅读对应脚本参数，并将输出限定在独立工作目录；不要覆盖个人数据库或复用历史运行目录。

## 执行与结果

`run-guarded-node.mjs` 配合文件监视器和进程内守卫记录运行情况。只有子进程成功、整体运行判定成功、监视器完整退出，才能判定该次运行通过。监视器正常停止不代表受测程序通过。

文件系统通知可能合并，通知数量不等同于实际操作数量；Node/Python 守卫也不能覆盖所有原生子进程操作。发现越界或监测失败时，应停止并保留现场供排查。

运行日志、诊断快照和历史验证材料保留在已忽略的本地工作目录中。
